# Finance Bot

Telegram-бот для личного бюджета: доходы, расходы, долги, цели, месячная сводка и подсказки о покупках.

## Возможности

- доходы с категориями: зарплата, аванс, квартальная премия и любые другие;
- расходы и топ категорий за текущий месяц;
- долги в обе стороны и финансовые цели;
- рекомендуемое распределение дохода;
- ответы «могу ли я себе это позволить?» и «стоит ли платить кредиткой?»;
- отдельная SQLite-база для данных каждого Telegram-пользователя;
- ограничение доступа по Telegram ID и понятное кнопочное меню.

Рекомендации являются ориентиром, а не профессиональной финансовой консультацией.

## Быстрый запуск

1. Создайте бота через `@BotFather` и получите токен.
2. Скопируйте `.env.example` в `.env`, вставьте токен. При желании укажите свой Telegram ID в `ALLOWED_USER_IDS`.
3. Запустите:

```bash
docker compose up -d --build
```

Без Docker:

```bash
python -m venv .venv
source .venv/bin/activate
pip install -r requirements.txt
python -m app.bot
```

Данные сохраняются в `data/finance.db`. Для резервной копии достаточно скопировать этот файл при остановленном боте.
